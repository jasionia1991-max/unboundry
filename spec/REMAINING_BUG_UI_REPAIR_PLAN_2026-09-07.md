### B2：模板超过100项也能完整管理

列表采用服务器分页，显示真实总数与上一页/下一页；保持 `updated_at DESC, rowid DESC` 与现有状态过滤语义，列表始终 `includeGraph=false`。以50项/页作为初始页面规模，查询与状态条件变化回第一页；请求包含查询、页码和序号，旧页迟到不能覆盖当前页。普通 offset 在他人编辑改变排序后可能漏项/重复：增加可选的列表修订标记，与筛选、分页数据在同一数据库读事务中核对；下一页携带标记，集合或排序变化时返回明确的“列表已变化”结果，前端提示并回到第一页刷新一次，不默默混用两次列表。来源选择维护自己的修订标记，已选 ID 不随刷新消失。旧客户端不传标记的行为保持兼容；不用全图快照、持久化快照表或 schema 迁移。标记生成只读轻量列表元数据，需验证同毫秒更新、归档/恢复及跨进程修改也能被检测，不能仅依赖进程内计数或 MAX(updated_at)。

本会话新增、修改、归档、恢复后主动重建列表修订并刷新第一页，保留原筛选与搜索条件；编辑中的模板/来源按 ID 独立持有，不因返回第一页串数据。频繁外部修改时保留明确刷新入口，不能无限自动刷新。验收“无重复/无漏项”限于同一未变化的列表修订；变化后的新列表须显式呈现，不宣称普通 offset 天然提供跨写入快照。
