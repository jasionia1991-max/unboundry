# INC-UI-010：管理员从画布组直接发布公共模板

状态：`LOCAL_IMPLEMENTED`
版本：`v0.6.16`
日期：`2026-08-18`

## 用户要的结果

管理员在画布上打组，点「创建模板」，可以直接发到公共模板。普通账号仍然只能存「我的模板」。组里的图清成空上传位，提示词、节点、连线留下。现有公共模板不改。

## 冻结合同

- 默认仍是「我的模板」，防止手滑。
- 只有具备「公共模板管理」的账号才看到「公共模板（所有人可见）」。
- 选公共后立刻上架，所有账号能看见、能导入。
- 发公共前单独洗掉私货素材编号和成片痕迹；个人保存路径完全不动。
- 分类：画布上选的一个分类，发公共时收成列表。
- 公共上架继续走原有兼容检查；失败停在弹窗，说人话，不半存。
- 不在画布上改已经上架的公共模板。
- 不改跨标签最后保存者胜，不改整组执行/下载/解组。

## 本发布范围

- 画布「创建模板」弹窗为有公共模板管理权限的账号增加保存去向。
- 发公共时清洗私货素材，保留提示词、节点和连线。
- 包版本升到 `0.6.16`。
- 用户确认按 `v0.6.16` 上线。
